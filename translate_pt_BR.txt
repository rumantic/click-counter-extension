MouseStat é uma extensão leve e eficiente para rastrear a atividade do seu mouse no navegador Chrome.

🎯 RECURSOS PRINCIPAIS:

✅ Contagem de Cliques do Mouse
• Contagem total de todos os cliques
• Estatísticas separadas para botão esquerdo, direito e do meio
• Rastreamento preciso de cada pressão

📏 Rastreamento de Movimento do Cursor
• Medição da distância percorrida pelo cursor em tempo real
• Conversão automática: centímetros → metros → quilômetros
• Descubra quantos "quilômetros" seu cursor percorre todos os dias!

🎡 Rastreamento da Roda de Rolagem
• Medição de rolagem vertical e horizontal
• Estatísticas separadas para distância rolada
• Você vai se surpreender com o quanto você rola ao ler artigos!

⚡ VANTAGENS:

🚀 Carga Mínima no Navegador
• Algoritmo otimizado com agrupamento de dados
• Não diminui a velocidade das páginas web
• Dados gravados uma vez a cada 2 segundos em vez de centenas de vezes por segundo

🔒 Privacidade Completa
• TODOS os dados são armazenados APENAS localmente no seu dispositivo
• NENHUM dado é transmitido para servidores externos
• NENHUMA informação pessoal é coletada
• Código aberto no GitHub

🌍 Multilíngue
• Suporte completo para idiomas russo e inglês
• Detecção automática do idioma do navegador

🎨 Interface Amigável
• Design bonito com tema gradiente
• Atualizações de estatísticas ao vivo a cada segundo
• Formatação de números com separadores de milhares para fácil leitura
• Página de configurações com opção de exclusão de dados

💡 FATOS INTERESSANTES:

• O usuário médio "percorre" 3-5 km com o cursor por dia
• A leitura ativa pode resultar em 5-10 km de rolagem por dia
• A distância total anual pode exceder 3000 km - isso é mais do que a distância de Moscou a Sochi!

🔧 COMO USAR:

1. Instale a extensão
2. Continue trabalhando normalmente
3. Clique no ícone do MouseStat para ver suas estatísticas
4. Surpreenda-se com os resultados!

📊 AS ESTATÍSTICAS INCLUEM:

• Total de cliques
• Cliques do botão esquerdo do mouse
• Cliques do botão direito do mouse
• Cliques do botão do meio (roda)
• Distância percorrida pelo cursor
• Distância da roda de rolagem

🛠️ RECURSOS TÉCNICOS:

• Usa Chrome Storage API para armazenamento local
• Event listeners passivos para desempenho máximo
• Agrupamento de atualizações para minimizar gravações em disco
• Salvamento automático ao fechar aba
