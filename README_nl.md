MouseStat is een lichtgewicht en efficiënte extensie voor het bijhouden van uw muisactiviteit in de Chrome-browser.

🎯 BELANGRIJKSTE FUNCTIES:

✅ Muisklik Tellen
• Totaal aantal van alle klikken
• Aparte statistieken voor linker-, rechter- en middelste knop
• Nauwkeurige tracking van elke druk

📏 Cursorbeweging Volgen
• Realtime meting van de afgelegde afstand van de cursor
• Automatische conversie: centimeters → meters → kilometers
• Ontdek hoeveel "kilometers" uw cursor elke dag aflegt!

🎡 Scrollwiel Volgen
• Verticale en horizontale scroll meting
• Aparte statistieken voor scroll afstand
• U zult versteld staan hoeveel u scrollt tijdens het lezen van artikelen!

⚡ VOORDELEN:

🚀 Minimale Browserbelasting
• Geoptimaliseerd algoritme met data batching
• Vertraagt webpagina's niet
• Data opgenomen eens per 2 seconden in plaats van honderden keren per seconde

🔒 Volledige Privacy
• ALLE data wordt ALLEEN lokaal op uw apparaat opgeslagen
• GEEN data verzonden naar externe servers
• GEEN persoonlijke informatie verzameld
• Open source op GitHub

🌍 Meertalig
• Volledige ondersteuning voor Russisch en Engels
• Automatische detectie van browsertaal

🎨 Gebruiksvriendelijke Interface
• Mooi ontwerp met verloopthema
• Live statistiek updates elke seconde
• Getalopmaak met duizendtallen scheidingstekens voor gemakkelijk lezen
• Instellingenpagina met optie om data te verwijderen

💡 INTERESSANTE FEITEN:

• De gemiddelde gebruiker "reist" 3-5 km met de cursor per dag
• Actief lezen kan resulteren in 5-10 km scrollen per dag
• De totale jaarlijkse afstand kan 3000 km overschrijden - dat is meer dan de afstand van Moskou naar Sotsji!

🔧 GEBRUIK:

1. Installeer de extensie
2. Ga door met werken zoals gewoonlijk
3. Klik op het MouseStat pictogram om uw statistieken te zien
4. Wees verbaasd over de resultaten!

📊 STATISTIEKEN OMVATTEN:

• Totaal aantal klikken
• Linker muisknop klikken
• Rechter muisknop klikken
• Middelste knop klikken (wiel)
• Afgelegde afstand door cursor
• Scrollwiel afstand

🛠️ TECHNISCHE KENMERKEN:

• Gebruikt Chrome Storage API voor lokale opslag
• Passieve event listeners voor maximale prestaties
• Update batching om schijfschrijfbewerkingen te minimaliseren
• Automatisch opslaan bij het sluiten van tabblad

🔗 OPEN SOURCE:

De broncode van de extensie is beschikbaar op GitHub: github.com/rumantic/click-counter-extension
U kunt de code controleren, verbeteringen bijdragen of problemen melden.

🎁 VOLLEDIG GRATIS:

• Geen advertenties
• Geen verborgen kosten
• Geen gegevensverzameling
• Geen functiebeperkingen

Probeer MouseStat en ontdek hoe actief uw muis is!
