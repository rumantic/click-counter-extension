Расширение для подсчета кликов мышкой пользователя и отслеживания пройденного курсором расстояния в браузере Chrome.

## Возможности

- ✅ Подсчет общего количества кликов
- ✅ Раздельный подсчет кликов левой, правой и средней кнопки мыши
- ✅ **Отслеживание дистанции, пройденной курсором мыши** 📏
- ✅ **Отслеживание прокрученной дистанции колесиком мыши** 🎡
- ✅ Автоматическая конвертация: сантиметры → метры → километры
- ✅ **Мультиязычность: русский 🇷🇺 и английский 🇬🇧**
- ✅ **Кнопка "Поделиться" для генерации изображения со статистикой** 📤
- ✅ Оптимизированный алгоритм с минимальной нагрузкой на браузер
- ✅ Сохранение статистики между сеансами
- ✅ Возможность сброса счетчика
- ✅ Красивый интерфейс popup с живым обновлением

## Установка

1. Откройте Chrome и перейдите по адресу `chrome://extensions/`
2. Включите "Режим разработчика" в правом верхнем углу
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку с расширением `click-counter-extension`
5. Расширение установлено! Иконка появится на панели инструментов

## Использование

1. После установки расширение автоматически начнет считать клики, отслеживать движение курсора и прокрутку колесиком на всех веб-страницах
2. Кликните по иконке расширения, чтобы увидеть статистику
3. Статистика обновляется автоматически каждую секунду
4. Нажмите кнопку "Сбросить счетчик", чтобы обнулить все значения
5. **Нажмите кнопку "Поделиться" (📤), чтобы сгенерировать красивое изображение со своей статистикой для публикации в социальных сетях** 🎉

## Как работает отслеживание

Расширение отслеживает движение курсора, прокрутку колесиком и вычисляет пройденные расстояния с помощью:
- **Оптимизированного алгоритма батчинга** - вычисления в памяти, запись раз в 2 секунды
- **Passive event listeners** - не блокируют UI браузера
- **Автоматической конвертации** единиц: см → м → км
- **Сохранения при закрытии вкладки** - данные не теряются

**Производительность:**
- ⚡ Минимальная нагрузка на процессор
- 💾 Запись в storage только раз в 2 секунды (вместо 60-100 раз/сек)
- 🚀 Не влияет на скорость работы браузера

## Технические детали

### Оптимизация производительности:

**Батчинг (пакетирование) обновлений:**
```javascript
// Вместо 60-100 записей в секунду → 1 запись в 2 секунды
let accumulatedDistance = 0;
setInterval(saveDistance, 2000); // Запись раз в 2 сек
```

**Passive event listeners:**
```javascript
document.addEventListener('mousemove', handler, { passive: true });
// Не блокирует скролл и другие действия
```

**Сохранение при закрытии:**
```javascript
window.addEventListener('beforeunload', saveDistance);
// Данные не потеряются
```

### Вычисления:
- **Расстояние**: теорема Пифагора для евклидова расстояния
- **Конвертация**: 96 пикселей ≈ 1 дюйм ≈ 2.54 см
- **Хранение**: Chrome Storage API (локально)

### Локализация:
- **Автоматическое определение языка** браузера
- **Поддерживаемые языки**: русский (ru) и английский (en)
- **По умолчанию**: русский язык
- **API i18n**: `chrome.i18n.getMessage()` для динамической загрузки переводов

## Интересные факты

🖱️ **Знаете ли вы?**
- Среднестатистический офисный работник "проходит" курсором **3-5 км в день**

- За год суммарная дистанция (курсор + прокрутка) может превысить **3000 км**!
