MouseStat adalah ekstensi ringan dan efisien untuk melacak aktivitas mouse Anda di browser Chrome.

🎯 FITUR UTAMA:

✅ Penghitungan Klik Mouse
• Total jumlah semua klik
• Statistik terpisah untuk tombol kiri, kanan, dan tengah
• Pelacakan tepat setiap penekanan

📏 Pelacakan Gerakan Kursor
• Pengukuran jarak perjalanan kursor secara real-time
• Konversi otomatis: sentimeter → meter → kilometer
• Temukan berapa "kilometer" kursor Anda bergerak setiap hari!

🎡 Pelacakan Roda Gulir
• Pengukuran gulir vertikal dan horizontal
• Statistik terpisah untuk jarak gulir
• Anda akan terkejut dengan seberapa banyak Anda menggulir saat membaca artikel!

⚡ KEUNGGULAN:

🚀 Beban Browser Minimal
• Algoritma yang dioptimalkan dengan batching data
• Tidak memperlambat halaman web
• Data direkam sekali setiap 2 detik alih-alih ratusan kali per detik

🔒 Privasi Lengkap
• SEMUA data disimpan HANYA secara lokal di perangkat Anda
• TIDAK ada data yang dikirim ke server eksternal
• TIDAK ada informasi pribadi yang dikumpulkan
• Sumber terbuka di GitHub

🌍 Multibahasa
• Dukungan penuh untuk bahasa Rusia dan Inggris
• Deteksi bahasa browser otomatis

🎨 Antarmuka Ramah Pengguna
• Desain indah dengan tema gradien
• Pembaruan statistik langsung setiap detik
• Format angka dengan pemisah ribuan untuk kemudahan membaca
• Halaman pengaturan dengan opsi penghapusan data

💡 FAKTA MENARIK:

• Pengguna rata-rata "menempuh" 3-5 km dengan kursor per hari
• Membaca aktif dapat menghasilkan 5-10 km pengguliran per hari
• Total jarak tahunan bisa melebihi 3000 km - itu lebih dari jarak dari Moskow ke Sochi!

🔧 CARA MENGGUNAKAN:

1. Instal ekstensi
2. Lanjutkan bekerja seperti biasa
3. Klik ikon MouseStat untuk melihat statistik Anda
4. Bersiaplah untuk terkejut dengan hasilnya!

📊 STATISTIK MELIPUTI:

• Total klik
• Klik tombol mouse kiri
• Klik tombol mouse kanan
• Klik tombol tengah (roda)
• Jarak yang ditempuh kursor
• Jarak roda gulir

🛠️ FITUR TEKNIS:

• Menggunakan Chrome Storage API untuk penyimpanan lokal
• Passive event listeners untuk performa maksimal
• Batching pembaruan untuk meminimalkan penulisan disk
• Penyimpanan otomatis saat menutup tab

🔗 SUMBER TERBUKA:

Kode sumber ekstensi tersedia di GitHub: github.com/rumantic/click-counter-extension
Anda dapat meninjau kode, berkontribusi perbaikan, atau melaporkan masalah.

🎁 SEPENUHNYA GRATIS:

• Tanpa iklan
• Tanpa biaya tersembunyi
• Tanpa pengumpulan data
• Tanpa batasan fitur

Coba MouseStat dan temukan seberapa aktif mouse Anda!
