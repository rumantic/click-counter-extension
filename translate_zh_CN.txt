MouseStat 是一款轻量高效的 Chrome 浏览器扩展，用于跟踪您的鼠标活动。

🎯 主要功能：

✅ 鼠标点击计数
• 所有点击的总数统计
• 左键、右键和中键的独立统计
• 精确跟踪每次按压

📏 光标移动跟踪
• 实时测量光标移动距离
• 自动转换：厘米 → 米 → 千米
• 发现您的光标每天"行走"多少公里！

🎡 滚轮滚动跟踪
• 垂直和水平滚动测量
• 独立的滚动距离统计
• 您会惊讶于阅读文章时滚动了多少距离！

⚡ 优势：

🚀 浏览器负载最小
• 优化的算法，采用数据批处理
• 不会减慢网页加载速度
• 每 2 秒记录一次数据，而不是每秒数百次

🔒 完全隐私保护
• 所有数据仅存储在您的本地设备上
• 不向外部服务器传输任何数据
• 不收集个人信息
• 在 GitHub 上开源

🌍 多语言支持
• 完全支持俄语和英语
• 自动检测浏览器语言

🎨 友好的用户界面
• 美观的渐变主题设计
• 每秒实时更新统计数据
• 数字格式化，带千位分隔符，便于阅读
• 设置页面，可选择删除数据

💡 有趣的事实：

• 普通用户每天用光标"行走" 3-5 公里
• 积极阅读可能导致每天滚动 5-10 公里
• 年度总距离可能超过 3000 公里 - 比从莫斯科到索契的距离还要远！

🔧 使用方法：

1. 安装扩展程序
2. 像往常一样继续工作
3. 点击 MouseStat 图标查看您的统计数据
4. 准备好为结果感到惊讶吧！

📊 统计数据包括：

• 总点击次数
• 鼠标左键点击次数
• 鼠标右键点击次数
• 中键点击次数（滚轮）
• 光标移动距离
• 滚轮滚动距离

🛠️ 技术特性：

• 使用 Chrome Storage API 进行本地存储
• 被动事件监听器以获得最佳性能
• 批量更新以最小化磁盘写入
• 关闭标签页时自动保存

扩展程序的源代码可在 GitHub 上获取：github.com/rumantic/click-counter-extension
您可以查看代码、贡献改进或报告问题。

• 无隐藏费用
• 无数据收集
• 无功能限制
