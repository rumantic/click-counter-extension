MouseStat ist eine leichte und effiziente Erweiterung zur Verfolgung Ihrer Mausaktivität im Chrome-Browser.

🎯 HAUPTFUNKTIONEN:

✅ Mausklick-Zählung
• Gesamtanzahl aller Klicks
• Separate Statistiken für linke, rechte und mittlere Taste
• Präzise Verfolgung jedes Drucks

📏 Cursor-Bewegungsverfolgung
• Echtzeitmessung der vom Cursor zurückgelegten Strecke
• Automatische Umrechnung: Zentimeter → Meter → Kilometer
• Entdecken Sie, wie viele "Kilometer" Ihr Cursor täglich zurücklegt!

🎡 Scrollrad-Verfolgung
• Messung von vertikalem und horizontalem Scrollen
• Separate Statistiken für Scroll-Distanz
• Sie werden überrascht sein, wie viel Sie beim Lesen von Artikeln scrollen!

⚡ VORTEILE:

🚀 Minimale Browser-Last
• Optimierter Algorithmus mit Daten-Batching
• Verlangsamt Webseiten nicht
• Datenaufzeichnung einmal alle 2 Sekunden statt hundertmal pro Sekunde

🔒 Vollständiger Datenschutz
• ALLE Daten werden NUR lokal auf Ihrem Gerät gespeichert
• KEINE Datenübertragung an externe Server
• KEINE Erfassung persönlicher Informationen
• Open Source auf GitHub

🌍 Mehrsprachigkeit
• Vollständige Unterstützung für Russisch und Englisch
• Automatische Erkennung der Browser-Sprache

🎨 Benutzerfreundliche Oberfläche
• Schönes Design mit Farbverlauf-Theme
• Live-Statistik-Updates jede Sekunde
• Zahlenformatierung mit Tausendertrennzeichen für einfaches Lesen
• Einstellungsseite mit Datenlöschungsoption

💡 INTERESSANTE FAKTEN:

• Der durchschnittliche Benutzer "läuft" täglich 3-5 km mit dem Cursor
• Aktives Lesen kann zu 5-10 km Scrollen pro Tag führen
• Die jährliche Gesamtstrecke kann 3000 km überschreiten - das ist mehr als die Entfernung von Moskau nach Sotschi!

🔧 VERWENDUNG:

1. Installieren Sie die Erweiterung
2. Arbeiten Sie wie gewohnt weiter
3. Klicken Sie auf das MouseStat-Symbol, um Ihre Statistiken zu sehen
4. Seien Sie überrascht von den Ergebnissen!

📊 STATISTIKEN UMFASSEN:

• Gesamtklicks
• Klicks mit der linken Maustaste
• Klicks mit der rechten Maustaste
• Klicks mit der mittleren Taste (Rad)
• Vom Cursor zurückgelegte Strecke
• Scrollrad-Distanz

🛠️ TECHNISCHE MERKMALE:

• Verwendet Chrome Storage API für lokale Speicherung
• Passive Event-Listener für maximale Performance
• Update-Batching zur Minimierung von Festplattenschreibvorgängen
• Automatisches Speichern beim Schließen des Tabs

🔗 OPEN SOURCE:

Der Quellcode der Erweiterung ist auf GitHub verfügbar: github.com/rumantic/click-counter-extension
Sie können den Code überprüfen, Verbesserungen beitragen oder Probleme melden.

🎁 VÖLLIG KOSTENLOS:

• Keine Werbung
• Keine versteckten Gebühren
• Keine Datenerfassung
• Keine Funktionseinschränkungen

Probieren Sie MouseStat aus und finden Sie heraus, wie aktiv Ihre Maus ist!
