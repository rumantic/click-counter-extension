MouseStat เป็นส่วนขยายที่มีน้ำหนักเบาและมีประสิทธิภาพสำหรับติดตามกิจกรรมเมาส์ของคุณในเบราว์เซอร์ Chrome

🎯 ฟีเจอร์หลัก:

✅ การนับคลิกเมาส์
• จำนวนคลิกทั้งหมด
• สถิติแยกต่างหากสำหรับปุ่มซ้าย ขวา และกลาง
• การติดตามที่แม่นยำของการกดทุกครั้ง

📏 การติดตามการเคลื่อนไหวของเคอร์เซอร์
• การวัดระยะทางการเดินทางของเคอร์เซอร์แบบเรียลไทม์
• การแปลงอัตโนมัติ: เซนติเมตร → เมตร → กิโลเมตร
• ค้นพบว่าเคอร์เซอร์ของคุณเดินทาง "กี่กิโลเมตร" ในแต่ละวัน!

🎡 การติดตามล้อเลื่อน
• การวัดการเลื่อนในแนวตั้งและแนวนอน
• สถิติแยกต่างหากสำหรับระยะทางการเลื่อน
• คุณจะประหลาดใจกับจำนวนการเลื่อนเมื่ออ่านบทความ!

⚡ ข้อดี:

🚀 ภาระโหลดเบราว์เซอร์ขั้นต่ำ
• อัลกอริทึมที่ปรับให้เหมาะสมพร้อมการจัดกลุ่มข้อมูล
• ไม่ทำให้หน้าเว็บช้าลง
• บันทึกข้อมูลทุก 2 วินาทีแทนที่จะเป็นหลายร้อยครั้งต่อวินาที

🔒 ความเป็นส่วนตัวสมบูรณ์
• ข้อมูลทั้งหมดจัดเก็บในเครื่องของคุณเท่านั้น
• ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ภายนอก
• ไม่มีการรวบรวมข้อมูลส่วนบุคคล
• โอเพนซอร์สบน GitHub

🌍 รองรับหลายภาษา
• รองรับภาษารัสเซียและอังกฤษอย่างเต็มรูปแบบ
• ตรวจจับภาษาเบราว์เซอร์อัตโนมัติ

🎨 อินเทอร์เฟซที่ใช้งานง่าย
• ดีไซน์สวยงามด้วยธีมไล่สี
• อัปเดตสถิติสดทุกวินาที
• การจัดรูปแบบตัวเลขด้วยตัวคั่นหลักพันเพื่อการอ่านที่ง่าย
• หน้าการตั้งค่าพร้อมตัวเลือกลบข้อมูล

💡 ข้อเท็จจริงที่น่าสนใจ:

• ผู้ใช้โดยเฉลี่ย "เดินทาง" 3-5 กม. ด้วยเคอร์เซอร์ต่อวัน
• การอ่านอย่างกระตือรือร้นอาจส่งผลให้เลื่อน 5-10 กม. ต่อวัน
• ระยะทางรวมต่อปีอาจเกิน 3,000 กม. - นั่นมากกว่าระยะทางจากมอสโกไปโซชี!

🔧 วิธีใช้งาน:

1. ติดตั้งส่วนขยาย
2. ทำงานต่อไปตามปกติ
3. คลิกไอคอน MouseStat เพื่อดูสถิติของคุณ
4. เตรียมตัวประหลาดใจกับผลลัพธ์!

📊 สถิติรวมถึง:

• คลิกทั้งหมด
• คลิกปุ่มซ้ายเมาส์
• คลิกปุ่มขวาเมาส์
• คลิกปุ่มกลาง (ล้อ)
• ระยะทางที่เคอร์เซอร์เดินทาง
• ระยะทางล้อเลื่อน

🛠️ คุณสมบัติทางเทคนิค:

• ใช้ Chrome Storage API สำหรับการจัดเก็บในเครื่อง
• Event listeners แบบ Passive เพื่อประสิทธิภาพสูงสุด
• การจัดกลุ่มการอัปเดตเพื่อลดการเขียนดิสก์
• บันทึกอัตโนมัติเมื่อปิดแท็บ

🔗 โอเพนซอร์ส:

ซอร์สโค้ดของส่วนขยายมีให้บน GitHub: github.com/rumantic/click-counter-extension
คุณสามารถตรวจสอบโค้ด มีส่วนร่วมในการปรับปรุง หรือรายงานปัญหา

🎁 ฟรีโดยสมบูรณ์:

• ไม่มีโฆษณา
• ไม่มีค่าธรรมเนียมซ่อนเร้น
• ไม่มีการรวบรวมข้อมูล
• ไม่มีข้อจำกัดฟีเจอร์

ลอง MouseStat และค้นหาว่าเมาส์ของคุณมีความกระตือรือร้นแค่ไหน!
