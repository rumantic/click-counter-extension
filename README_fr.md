MouseStat est une extension légère et efficace pour suivre l'activité de votre souris dans le navigateur Chrome.

🎯 FONCTIONNALITÉS PRINCIPALES :

✅ Comptage des Clics de Souris
• Nombre total de tous les clics
• Statistiques séparées pour les boutons gauche, droit et central
• Suivi précis de chaque pression

📏 Suivi du Mouvement du Curseur
• Mesure de la distance parcourue par le curseur en temps réel
• Conversion automatique : centimètres → mètres → kilomètres
• Découvrez combien de "kilomètres" votre curseur parcourt chaque jour !

🎡 Suivi de la Molette de Défilement
• Mesure du défilement vertical et horizontal
• Statistiques séparées pour la distance de défilement
• Vous serez surpris par la distance que vous faites défiler en lisant des articles !

⚡ AVANTAGES :

🚀 Charge Minimale du Navigateur
• Algorithme optimisé avec traitement par lots de données
• Ne ralentit pas les pages web
• Enregistrement des données une fois toutes les 2 secondes au lieu de centaines de fois par seconde

🔒 Confidentialité Totale
• TOUTES les données sont stockées UNIQUEMENT localement sur votre appareil
• AUCUNE donnée n'est transmise vers des serveurs externes
• AUCUNE information personnelle n'est collectée
• Code source ouvert sur GitHub

🌍 Multilingue
• Support complet pour les langues russe et anglaise
• Détection automatique de la langue du navigateur

🎨 Interface Conviviale
• Design élégant avec thème dégradé
• Mises à jour des statistiques en direct chaque seconde
• Formatage des nombres avec séparateurs de milliers pour une lecture facile
• Page de paramètres avec option de suppression des données

💡 FAITS INTÉRESSANTS :

• L'utilisateur moyen "parcourt" 3-5 km avec le curseur par jour
• La lecture active peut entraîner 5-10 km de défilement par jour
• La distance totale annuelle peut dépasser 3000 km - c'est plus que la distance de Moscou à Sotchi !

🔧 UTILISATION :

1. Installez l'extension
2. Continuez à travailler comme d'habitude
3. Cliquez sur l'icône MouseStat pour voir vos statistiques
4. Soyez surpris par les résultats !

📊 LES STATISTIQUES INCLUENT :

• Total des clics
• Clics du bouton gauche de la souris
• Clics du bouton droit de la souris
• Clics du bouton central (molette)
• Distance parcourue par le curseur
• Distance de la molette de défilement

🛠️ CARACTÉRISTIQUES TECHNIQUES :

• Utilise l'API Chrome Storage pour le stockage local
• Écouteurs d'événements passifs pour des performances maximales
• Traitement par lots des mises à jour pour minimiser les écritures sur le disque
• Sauvegarde automatique lors de la fermeture de l'onglet

🔗 CODE OPEN SOURCE :

Le code source de l'extension est disponible sur GitHub : github.com/rumantic/click-counter-extension
Vous pouvez examiner le code, contribuer des améliorations ou signaler des problèmes.

🎁 ENTIÈREMENT GRATUIT :

• Sans publicité
• Sans frais cachés
• Sans collecte de données
• Sans limitations de fonctionnalités

Essayez MouseStat et découvrez à quel point votre souris est active !
