MouseStat es una extensión ligera y eficiente para rastrear la actividad de tu mouse en el navegador Chrome.

🎯 CARACTERÍSTICAS PRINCIPALES:

✅ Conteo de Clics del Mouse
• Conteo total de todos los clics
• Estadísticas separadas para botón izquierdo, derecho y central
• Seguimiento preciso de cada pulsación

📏 Seguimiento de Movimiento del Cursor
• Medición de la distancia recorrida por el cursor en tiempo real
• Conversión automática: centímetros → metros → kilómetros
• ¡Descubre cuántos "kilómetros" recorre tu cursor cada día!

🎡 Seguimiento de Rueda de Desplazamiento
• Medición de desplazamiento vertical y horizontal
• Estadísticas separadas para distancia desplazada
• ¡Te sorprenderás de cuánto desplazas al leer artículos!

⚡ VENTAJAS:

🚀 Carga Mínima del Navegador
• Algoritmo optimizado con agrupación de datos
• No ralentiza las páginas web
• Datos registrados una vez cada 2 segundos en lugar de cientos de veces por segundo

🔒 Privacidad Completa
• TODOS los datos se almacenan SOLO localmente en tu dispositivo
• NO se transmiten datos a servidores externos
• NO se recopila información personal
• Código abierto en GitHub

🌍 Multilingüe
• Soporte completo para idiomas ruso e inglés
• Detección automática del idioma del navegador

🎨 Interfaz Amigable
• Diseño hermoso con tema degradado
• Actualizaciones de estadísticas en vivo cada segundo
• Formato de números con separadores de miles para fácil lectura
• Página de configuración con opción de eliminación de datos

💡 DATOS INTERESANTES:

• El usuario promedio "recorre" 3-5 km con el cursor por día
• La lectura activa puede resultar en 5-10 km de desplazamiento por día
• ¡La distancia total anual puede superar los 3000 km - más que la distancia de Moscú a Sochi!

🔧 CÓMO USAR:

1. Instala la extensión
2. Continúa trabajando como de costumbre
3. Haz clic en el ícono de MouseStat para ver tus estadísticas
4. ¡Sorpréndete con los resultados!

📊 LAS ESTADÍSTICAS INCLUYEN:

• Total de clics
• Clics del botón izquierdo del mouse
• Clics del botón derecho del mouse
• Clics del botón central (rueda)
• Distancia recorrida por el cursor
• Distancia de la rueda de desplazamiento

🛠️ CARACTERÍSTICAS TÉCNICAS:

• Utiliza Chrome Storage API para almacenamiento local
• Oyentes de eventos pasivos para máximo rendimiento
• Agrupación de actualizaciones para minimizar escrituras en disco
• Guardado automático al cerrar pestaña

🔗 CÓDIGO ABIERTO:

El código fuente de la extensión está disponible en GitHub: github.com/rumantic/click-counter-extension
Puedes revisar el código, contribuir con mejoras o reportar problemas.

🎁 COMPLETAMENTE GRATIS:

• Sin anuncios
• Sin tarifas ocultas
• Sin recopilación de datos
• Sin limitaciones de funciones

¡Prueba MouseStat y descubre qué tan activo es tu mouse!
