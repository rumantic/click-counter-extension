Το MouseStat είναι μια ελαφριά και αποτελεσματική επέκταση για την παρακολούθηση της δραστηριότητας του ποντικιού σας στο πρόγραμμα περιήγησης Chrome.

🎯 ΒΑΣΙΚΑ ΧΑΡΑΚΤΗΡΙΣΤΙΚΑ:

✅ Καταμέτρηση κλικ ποντικιού
• Συνολικός αριθμός όλων των κλικ
• Ξεχωριστά στατιστικά για αριστερό, δεξί και μεσαίο κουμπί
• Ακριβής παρακολούθηση κάθε πατήματος

📏 Παρακολούθηση κίνησης δρομέα
• Μέτρηση της απόστασης που διανύει ο δρομέας σε πραγματικό χρόνο
• Αυτόματη μετατροπή: εκατοστά → μέτρα → χιλιόμετρα
• Ανακαλύψτε πόσα "χιλιόμετρα" διανύει ο δρομέας σας κάθε μέρα!

🎡 Παρακολούθηση τροχού κύλισης
• Μέτρηση κάθετης και οριζόντιας κύλισης
• Ξεχωριστά στατιστικά για την απόσταση κύλισης
• Θα εκπλαγείτε με το πόσο κυλάτε όταν διαβάζετε άρθρα!

⚡ ΠΛΕΟΝΕΚΤΗΜΑΤΑ:

🚀 Ελάχιστος φόρτος στο πρόγραμμα περιήγησης
• Βελτιστοποιημένος αλγόριθμος με ομαδοποίηση δεδομένων
• Δεν επιβραδύνει τις ιστοσελίδες
• Καταγραφή δεδομένων μία φορά ανά 2 δευτερόλεπτα αντί για εκατοντάδες φορές ανά δευτερόλεπτο

🔒 Πλήρης ιδιωτικότητα
• ΟΛΑ τα δεδομένα αποθηκεύονται ΜΟΝΟ τοπικά στη συσκευή σας
• ΔΕΝ μεταδίδονται δεδομένα σε εξωτερικούς διακομιστές
• ΔΕΝ συλλέγονται προσωπικές πληροφορίες
• Ανοιχτός κώδικας στο GitHub

🌍 Πολυγλωσσικό
• Πλήρης υποστήριξη ρωσικής και αγγλικής γλώσσας
• Αυτόματος εντοπισμός γλώσσας προγράμματος περιήγησης

🎨 Φιλική προς το χρήστη διεπαφή
• Όμορφος σχεδιασμός με θέμα ντεγκραντέ
• Ζωντανές ενημερώσεις στατιστικών κάθε δευτερόλεπτο
• Μορφοποίηση αριθμών με διαχωριστικά χιλιάδων για εύκολη ανάγνωση
• Σελίδα ρυθμίσεων με επιλογή διαγραφής δεδομένων

💡 ΕΝΔΙΑΦΕΡΟΝΤΑ ΣΤΟΙΧΕΙΑ:

• Ο μέσος χρήστης "διανύει" 3-5 χλμ με τον δρομέα ανά ημέρα
• Η ενεργή ανάγνωση μπορεί να οδηγήσει σε 5-10 χλμ κύλισης ανά ημέρα
• Η συνολική ετήσια απόσταση μπορεί να υπερβεί τα 3000 χλμ - είναι περισσότερο από την απόσταση από τη Μόσχα στο Σότσι!

🔧 ΤΡΟΠΟΣ ΧΡΗΣΗΣ:

1. Εγκαταστήστε την επέκταση
2. Συνεχίστε να εργάζεστε όπως συνήθως
3. Κάντε κλικ στο εικονίδιο MouseStat για να δείτε τα στατιστικά σας
4. Εκπλαγείτε με τα αποτελέσματα!

📊 ΤΑ ΣΤΑΤΙΣΤΙΚΑ ΠΕΡΙΛΑΜΒΑΝΟΥΝ:

• Συνολικά κλικ
• Κλικ αριστερού κουμπιού ποντικιού
• Κλικ δεξιού κουμπιού ποντικιού
• Κλικ μεσαίου κουμπιού (τροχός)
• Απόσταση που διανύθηκε από τον δρομέα
• Απόσταση κύλισης τροχού

🛠️ ΤΕΧΝΙΚΑ ΧΑΡΑΚΤΗΡΙΣΤΙΚΑ:

• Χρησιμοποιεί το Chrome Storage API για τοπική αποθήκευση
• Παθητικοί ακροατές συμβάντων για μέγιστη απόδοση
• Ομαδοποίηση ενημερώσεων για ελαχιστοποίηση εγγραφών στο δίσκο
• Αυτόματη αποθήκευση κατά το κλείσιμο της καρτέλας

🔗 ΑΝΟΙΧΤΟΣ ΚΩΔΙΚΑΣ:

Ο πηγαίος κώδικας της επέκτασης είναι διαθέσιμος στο GitHub: github.com/rumantic/click-counter-extension
Μπορείτε να ελέγξετε τον κώδικα, να συνεισφέρετε βελτιώσεις ή να αναφέρετε προβλήματα.

🎁 ΕΝΤΕΛΩΣ ΔΩΡΕΑΝ:

• Χωρίς διαφημίσεις
• Χωρίς κρυφές χρεώσεις
• Χωρίς συλλογή δεδομένων
• Χωρίς περιορισμούς λειτουργιών

Δοκιμάστε το MouseStat και ανακαλύψτε πόσο ενεργό είναι το ποντίκι σας!
