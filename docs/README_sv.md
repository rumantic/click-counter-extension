MouseStat är en lätt och effektiv förlängning för att spåra din musaktivitet i Chrome-webbläsaren.

🎯 HUVUDFUNKTIONER:

✅ Musklicksräkning
• Totalt antal alla klick
• Separat statistik för vänster, höger och mittenknapp
• Exakt spårning av varje tryck

📏 Markörrörelsspårning
• Realtidsmätning av sträckan som markören färdas
• Automatisk konvertering: centimeter → meter → kilometer
• Upptäck hur många "kilometer" din markör färdas varje dag!

🎡 Rullhjulsspårning
• Mätning av vertikal och horisontell rullning
• Separat statistik för rullad sträcka
• Du kommer att bli förvånad över hur mycket du rullar när du läser artiklar!

⚡ FÖRDELAR:

🚀 Minimal Webbläsarbelastning
• Optimerad algoritm med databatchning
• Saktar inte ner webbsidor
• Data registreras en gång var 2:a sekund istället för hundratals gånger per sekund

🔒 Fullständig Integritet
• ALL data lagras ENDAST lokalt på din enhet
• INGEN data överförs till externa servrar
• INGEN personlig information samlas in
• Öppen källkod på GitHub

🌍 Flerspråkig
• Fullständigt stöd för ryska och engelska
• Automatisk identifiering av webbläsarspråk

🎨 Användarvänligt Gränssnitt
• Vacker design med gradienttema
• Live statistikuppdateringar varje sekund
• Nummerformatering med tusentalsavgränsare för enkel läsning
• Inställningssida med alternativ för dataradering

💡 INTRESSANTA FAKTA:

• Genomsnittlig användare "reser" 3-5 km med markören per dag
• Aktivt läsande kan resultera i 5-10 km rullning per dag
• Det årliga totalavståndet kan överskrida 3000 km - det är mer än avståndet från Moskva till Sotji!

🔧 HUR MAN ANVÄNDER:

1. Installera förlängningen
2. Fortsätt arbeta som vanligt
3. Klicka på MouseStat-ikonen för att se din statistik
4. Bli förvånad över resultaten!

📊 STATISTIKEN INKLUDERAR:

• Totalt antal klick
• Vänster musknapp klick
• Höger musknapp klick
• Mittenknapp klick (hjul)
• Sträcka som markören färdats
• Rullhjulssträcka

🛠️ TEKNISKA FUNKTIONER:

• Använder Chrome Storage API för lokal lagring
• Passiva händelselyssnare för maximal prestanda
• Uppdateringsbatchning för att minimera diskskrivningar
• Automatisk sparning vid stängning av flik

🔗 ÖPPEN KÄLLKOD:

Förlängningens källkod finns tillgänglig på GitHub: github.com/rumantic/click-counter-extension
Du kan granska koden, bidra med förbättringar eller rapportera problem.

🎁 HELT GRATIS:

• Ingen reklam
• Inga dolda avgifter
• Ingen datainsamling
• Inga funktionsbegränsningar

Prova MouseStat och ta reda på hur aktiv din mus är!
