MouseStat - это легкое и эффективное расширение для отслеживания активности вашей мыши в браузере Chrome.

🎯 ОСНОВНЫЕ ФУНКЦИИ:

✅ Подсчет кликов мыши
• Общее количество всех кликов
• Раздельная статистика по левой, правой и средней кнопке
• Точный учет каждого нажатия

📏 Отслеживание перемещения курсора
• Измерение пройденного курсором расстояния в реальном времени
• Автоматическая конвертация: сантиметры → метры → километры
• Узнайте, сколько "километров" проходит ваш курсор каждый день!

🎡 Учет прокрутки колесиком
• Измерение вертикальной и горизонтальной прокрутки
• Отдельная статистика прокрученного расстояния
• Удивитесь, сколько вы прокручиваете при чтении статей!

⚡ ПРЕИМУЩЕСТВА:

🚀 Минимальная нагрузка на браузер
• Оптимизированный алгоритм с батчингом данных
• Не замедляет работу веб-страниц
• Запись данных раз в 2 секунды вместо сотен раз в секунду

🔒 Полная конфиденциальность
• ВСЕ данные хранятся ТОЛЬКО локально на вашем устройстве
• НЕ передаются никакие данные на внешние серверы
• НЕ собирается личная информация
• Открытый исходный код на GitHub

🌍 Мультиязычность
• Полная поддержка русского и английского языков
• Автоматическое определение языка браузера

🎨 Удобный интерфейс
• Красивый дизайн с градиентной темой
• Живое обновление статистики каждую секунду
• Форматирование чисел с разделителями тысяч для удобного чтения
• Страница настроек с возможностью удаления данных

💡 ИНТЕРЕСНЫЕ ФАКТЫ:

• Среднестатистический пользователь "проходит" курсором 3-5 км в день
• При активном чтении можно прокручивать 5-10 км в день колесиком
• За год суммарная дистанция может превысить 3000 км - это больше расстояния от Москвы до Сочи!

🔧 ИСПОЛЬЗОВАНИЕ:

1. Установите расширение
2. Продолжайте работать как обычно
3. Кликните по иконке MouseStat, чтобы увидеть свою статистику
4. Удивитесь результатам!

📊 СТАТИСТИКА ВКЛЮЧАЕТ:

• Всего кликов
• Клики левой кнопки мыши
• Клики правой кнопки мыши
• Клики средней кнопки (колесико)
• Дистанция, пройденная курсором
• Дистанция прокрутки колесиком

🛠️ ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ:

• Использует Chrome Storage API для локального хранения
• Passive event listeners для максимальной производительности
• Батчинг обновлений для минимизации записи на диск
• Автоматическое сохранение при закрытии вкладки

• Без ограничений функций
