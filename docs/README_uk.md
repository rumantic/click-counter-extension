MouseStat - це легке та ефективне розширення для відстеження активності вашої миші в браузері Chrome.

🎯 ОСНОВНІ ФУНКЦІЇ:

✅ Підрахунок Кліків Миші
• Загальна кількість усіх кліків
• Окремі статистики для лівої, правої та середньої кнопки
• Точне відстеження кожного натискання

📏 Відстеження Руху Курсора
• Вимірювання пройденої відстані курсора в реальному часі
• Автоматичне перетворення: сантиметри → метри → кілометри
• Дізнайтеся, скільки "кілометрів" проходить ваш курсор щодня!

🎡 Відстеження Колеса Прокручування
• Вимірювання вертикального та горизонтального прокручування
• Окремі статистики для відстані прокручування
• Ви здивуєтеся, скільки ви прокручуєте під час читання статей!

⚡ ПЕРЕВАГИ:

🚀 Мінімальне Навантаження на Браузер
• Оптимізований алгоритм із пакетною обробкою даних
• Не сповільнює веб-сторінки
• Дані записуються раз на 2 секунди замість сотень разів на секунду

🔒 Повна Конфіденційність
• ВСІ дані зберігаються ТІЛЬКИ локально на вашому пристрої
• ЖОДНИХ даних не передається на зовнішні сервери
• ЖОДНОЇ особистої інформації не збирається
• Відкритий код на GitHub

🌍 Багатомовність
• Повна підтримка російської та англійської мов
• Автоматичне визначення мови браузера

🎨 Зручний Інтерфейс
• Красивий дизайн із градієнтною темою
• Оновлення статистики в реальному часі щосекунди
• Форматування чисел із роздільниками тисяч для легкого читання
• Сторінка налаштувань з можливістю видалення даних

💡 ЦІКАВІ ФАКТИ:

• Середній користувач "проходить" 3-5 км курсором на день
• Активне читання може призвести до 5-10 км прокручування на день
• Річна загальна відстань може перевищити 3000 км - це більше ніж відстань від Москви до Сочі!

🔧 ЯК ВИКОРИСТОВУВАТИ:

1. Встановіть розширення
2. Продовжуйте працювати як зазвичай
3. Натисніть на іконку MouseStat, щоб побачити вашу статистику
4. Будьте готові здивуватися результатам!

📊 СТАТИСТИКА ВКЛЮЧАЄ:

• Загальна кількість кліків
• Кліки лівою кнопкою миші
• Кліки правою кнопкою миші
• Кліки середньою кнопкою (колесо)
• Відстань, пройдена курсором
• Відстань прокручування колеса

🛠️ ТЕХНІЧНІ ОСОБЛИВОСТІ:

• Використовує Chrome Storage API для локального зберігання
• Пасивні слухачі подій для максимальної продуктивності
• Пакетне оновлення для мінімізації записів на диск
• Автоматичне збереження при закритті вкладки

🔗 ВІДКРИТИЙ КОД:

Вихідний код розширення доступний на GitHub: github.com/rumantic/click-counter-extension
Ви можете переглянути код, зробити внесок у покращення або повідомити про проблеми.

🎁 ПОВНІСТЮ БЕЗКОШТОВНО:

• Без реклами
• Без прихованих платежів
• Без збору даних
• Без обмежень функцій

Спробуйте MouseStat і дізнайтеся, наскільки активна ваша миша!
