MouseStat은 Chrome 브라우저에서 마우스 활동을 추적하는 가볍고 효율적인 확장 프로그램입니다.

🎯 주요 기능:

✅ 마우스 클릭 카운팅
• 모든 클릭의 총 개수
• 왼쪽, 오른쪽 및 가운데 버튼의 개별 통계
• 모든 누름의 정확한 추적

📏 커서 이동 추적
• 실시간으로 커서 이동 거리 측정
• 자동 변환: 센티미터 → 미터 → 킬로미터
• 매일 커서가 얼마나 많은 "킬로미터"를 이동하는지 발견하세요!

🎡 스크롤 휠 추적
• 수직 및 수평 스크롤 측정
• 스크롤 거리에 대한 개별 통계
• 기사를 읽을 때 얼마나 많이 스크롤하는지 놀라실 겁니다!

⚡ 장점:

🚀 최소한의 브라우저 부하
• 데이터 일괄 처리를 사용한 최적화된 알고리즘
• 웹 페이지 속도를 늦추지 않음
• 초당 수백 번이 아닌 2초마다 한 번씩 데이터 기록

🔒 완전한 개인정보 보호
• 모든 데이터는 기기에만 로컬로 저장됨
• 외부 서버로 데이터가 전송되지 않음
• 개인 정보가 수집되지 않음
• GitHub에서 오픈 소스로 제공

🌍 다국어 지원
• 러시아어 및 영어 완벽 지원
• 브라우저 언어 자동 감지

🎨 사용자 친화적 인터페이스
• 그라데이션 테마의 아름다운 디자인
• 매초 실시간 통계 업데이트
• 쉬운 읽기를 위한 천 단위 구분 기호가 있는 숫자 형식
• 데이터 삭제 옵션이 있는 설정 페이지

💡 흥미로운 사실:

• 평균 사용자는 하루에 커서로 3-5km를 "이동"합니다
• 적극적인 읽기는 하루에 5-10km의 스크롤을 초래할 수 있습니다
• 연간 총 거리는 3000km를 초과할 수 있습니다 - 모스크바에서 소치까지의 거리보다 더 멉니다!

🔧 사용 방법:

1. 확장 프로그램 설치
2. 평소처럼 계속 작업
3. MouseStat 아이콘을 클릭하여 통계 확인
4. 결과에 놀라세요!

📊 통계 포함 항목:

• 총 클릭 수
• 왼쪽 마우스 버튼 클릭 수
• 오른쪽 마우스 버튼 클릭 수
• 가운데 버튼 클릭 수(휠)
• 커서가 이동한 거리
• 스크롤 휠 거리

🛠️ 기술적 특징:

• 로컬 저장을 위한 Chrome Storage API 사용
• 최대 성능을 위한 수동 이벤트 리스너
• 디스크 쓰기를 최소화하기 위한 업데이트 일괄 처리
• 탭을 닫을 때 자동 저장

🔗 오픈 소스:

확장 프로그램의 소스 코드는 GitHub에서 확인할 수 있습니다: github.com/rumantic/click-counter-extension
코드를 검토하고, 개선 사항을 기여하거나, 문제를 보고할 수 있습니다.

🎁 완전 무료:

• 광고 없음
• 숨겨진 요금 없음
• 데이터 수집 없음
• 기능 제한 없음

MouseStat을 사용해 보고 마우스가 얼마나 활동적인지 알아보세요!
